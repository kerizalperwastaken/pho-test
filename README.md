# pho-test

Sunbird / Phoenix plugin experiments.

## server-info

Shows server details in the guild menu, just above "Edit Per-server Profile",
in two columns (labels left, values right): name and ID, member and online
counts, role and channel counts, boost level and count, creation date, vanity
URL and description. Nothing is added to the header, channel list, composer
or profiles.

Source: `server-info/src/index.ts`. Bundle: `out/server-info.js`.

Install:

```
https://raw.githubusercontent.com/kerizalperwastaken/pho-test/main/out/server-info.js
```
